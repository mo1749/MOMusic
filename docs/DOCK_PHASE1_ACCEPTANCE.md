## 本轮修复

1. 新增「启动时恢复桌面模式」，默认关闭，位于桌面模式组，Dock 关闭时也可设置。与开机自启独立，不进入 FX 存档。
2. 修复启动时无条件关闭覆盖恢复意图；每次应用启动最多消费一次。自动恢复强制可交互、图标可见、软件未锁定。
3. 修复占位页定时器在主页加载期间中断导航：本地服务就绪后、主页导航前取消定时器；已经发起的占位页先等待完成。
4. 分离 Dock 实际 enabled 和 preferredEnabled；退出桌面模式回流关闭状态；persistState=false 时应用重启不恢复 Dock。
5. 关闭 Dock 时取消扫描、图标助手和崩溃重建定时器；旧窗口/助手/扫描回调不能覆盖新生命周期；空运行快照清除残留应用。
6. 设置写入和开机自启失败回滚并提示；设置请求串行，最终回显以主进程保存值为准；关闭 Dock 不留下应用中心快捷键。

## 人工验收步骤

1. 正常 `npm start`，打开 DIY → 视觉控制台 → 界面。恢复选项首次默认关闭；桌面模式关闭时 Dock 开关不可用，设置卡片隐藏。
2. 开启桌面模式与 Dock，检查设置卡片出现；在 Dock/桌面模式开关间快速切换，确认没有透明窗口吞掉桌面点击。
3. 测试设置回显、四边布局、固定、拖入、右键、搜索与窗口切换；确认在透明空白区域能操作原应用，在 Dock 上能正常点击。
4. 开启恢复选项，保持桌面模式与 Dock 开启后正常退出应用，再次 `npm start`：桌面图标可见、软件未锁定、Dock 恢复。按 Escape 退出后再次重启：不自动恢复桌面模式。
5. 关闭「保持上次状态」，退出并重新开启桌面模式：Dock 保持关闭；关闭恢复选项后重启也不自动进入桌面模式。
6. 检查自动隐藏唤出、全屏应用遮挡、主显示器/DPI 变化、新安装和卸载。开机自启和系统重启单独验证，完成后记录机器环境及结果。

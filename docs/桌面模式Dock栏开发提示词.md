# 桌面模式 Dock 栏开发提示词

> 使用说明：把本文件全文发给负责开发的 AI。如果对方支持图片输入，请同时附上"视觉控制台"界面截图，并在截图中标出 Dock 开关按钮的位置。

---

## 一、角色与任务

你是一名 Windows 桌面客户端开发工程师，同时负责界面设计。请在现有的"视觉控制台"程序中，新增一个桌面 Dock 栏功能。

Dock 栏是屏幕边缘的一条应用启动条，作用类似 macOS 的 Dock。用户把常用应用放在上面，可以一键启动、切换窗口、查看运行状态。

整体交互和视觉效果请参考以下四款成熟软件，并取它们的长处：

- **MyDockFinder（MyDock）**：仿 macOS 风格，动画流畅，有启动台、消息提醒、窗口预览、文件夹堆叠。
- **WinStep Nexus**：功能最全，有系统托盘嵌入、图标反射、小部件、多 Dock、子 Dock、自动隐藏、80 多个系统命令。
- **RocketDock**：轻量稳定，拖放简单，动画顺滑，适合参考基础交互。
- **ObjectDock**：支持多个 Dock 和标签分页，外观自定义程度高。

## 二、开关入口与联动逻辑（核心要求，必须严格实现）

### 2.1 开关位置

1. 在"视觉控制台"的界面中，找到"桌面模式"开关。
2. 在"桌面模式"开关的**左边**，新增一个"Dock 栏"开关按钮。
3. 两个开关的样式保持一致，排列整齐。具体位置参考附带的界面截图。

### 2.2 联动规则（状态逻辑）

Dock 栏开关必须和桌面模式联动，规则如下：

1. **桌面模式关闭时**：Dock 栏开关为禁用状态（灰色、不可点击）。鼠标悬停时提示"请先开启桌面模式"。
2. **桌面模式开启后**：Dock 栏开关变为可用状态，用户可以正常打开或关闭。
3. **Dock 栏开关打开后**：
   - 屏幕边缘显示 Dock 栏。
   - 桌面模式的设置卡片区域中，自动出现一张新卡片，卡片名称为"Dock 栏设置"。
4. **Dock 栏开关关闭后**：
   - Dock 栏立即隐藏。
   - "Dock 栏设置"卡片同时消失。
5. **桌面模式从开启变为关闭时**：
   - 如果 Dock 栏此时是打开状态，程序要一并关闭并隐藏 Dock 栏。
   - "Dock 栏设置"卡片同时消失。
   - 下次重新开启桌面模式时，Dock 栏是否恢复打开，由设置项"开机后保持上次状态"决定（见第三部分）。

请把以上逻辑画成状态流转图，先确认没有遗漏，再开始写代码。

## 三、"Dock 栏设置"卡片

Dock 栏开关打开后，这张卡片才出现在桌面模式的卡片组中。卡片内的设置项请分组排列，建议分为以下六组。

### 3.1 位置与固定

1. **固定 Dock 栏（锁定位置）**：开启后，Dock 栏不能被鼠标拖动，位置被锁定。关闭后用户可以把 Dock 拖到屏幕其他边缘。
2. **屏幕位置**：可选屏幕底部、顶部、左侧、右侧，默认底部。
3. **与屏幕边缘的距离**：滑块调节，Dock 栏可以紧贴边缘，也可以留出一点空隙。
4. **多显示器选择**：电脑接多个屏幕时，让用户选择 Dock 显示在哪个屏幕上；也可以选择"每个屏幕都显示"。

### 3.2 显示方式

1. **自动隐藏**：开启后，鼠标离开 Dock 时它自动收起；鼠标移到屏幕对应边缘时，它再滑出。
2. **始终置顶**：Dock 栏始终显示在普通窗口上方。
3. **全屏应用运行时自动隐藏**：用户看视频或玩游戏时，Dock 自动收起，不遮挡画面。
4. **开机后保持上次状态**：开启后，程序重启或桌面模式重新打开时，Dock 恢复到上次的开关状态。
5. **开机自动启动**：系统开机后程序和 Dock 自动运行。

### 3.3 主题与外观

1. **主题选择**：提供多套现成主题，例如 macOS 浅色、macOS 深色、毛玻璃、全透明、纯色等。
2. **自定义外观**：用户可以自行调整背景颜色、透明度、模糊程度、圆角大小。
3. **图标大小**：滑块调节图标默认尺寸。
4. **图标间距**：滑块调节图标之间的空隙。
5. **鼠标悬停放大效果**：开关 + 放大倍数滑块。鼠标划过图标时，附近图标依次放大，类似 macOS 的放大镜效果。
6. **图标倒影（反射）**：开关。开启后图标下方显示实时倒影，参考 Nexus。
7. **动画速度**：滑块调节放大、隐藏、弹出等动画的快慢。

### 3.4 系统区域与功能开关

1. **系统托盘显示开关**：开启后，Windows 右下角托盘区的图标（如 QQ、微信、音量、网络等）收纳并显示在 Dock 栏上；可以选择逐个显示，也可以合并成一个分组图标。关闭后托盘仍由 Windows 任务栏显示。
2. **运行状态指示器**：开启后，正在运行的应用图标下方显示一个小圆点。
3. **最小化窗口到 Dock**：开启后，窗口最小化时收进 Dock 对应图标中，可带"神奇效果"动画（至少提供两到三种最小化动画供选择）。
4. **悬停窗口预览**：开启后，鼠标悬停在运行中的应用图标上，会显示该应用窗口的缩略图，点击缩略图可以直接切换窗口。
5. **回收站**：可在 Dock 上显示回收站图标，支持拖文件进去删除、右键清空回收站。
6. **开始按钮 / 应用中心按钮**：控制这两个入口图标是否显示在 Dock 上。

### 3.5 小部件（参考 Nexus 的内置模块）

允许用户按需在 Dock 上添加或移除以下小部件：

1. 时钟（可带日期）
2. 天气（显示用户所在城市的实时天气和预报）
3. CPU 使用率监控
4. 内存使用率监控
5. 网络状态和网速监控
6. 音量控制
7. 电池状态（笔记本使用）
8. 邮件提醒

### 3.6 消息提醒（参考 MyDockFinder）

1. 开启后，微信、QQ、钉钉等常用聊天软件收到新消息时，Dock 上的对应图标会弹跳，并显示未读消息数量角标。
2. 用户可以分别设置每个软件是否参与提醒。

## 四、Dock 栏本体功能

### 4.1 区域划分

Dock 栏从左到右（竖屏时从上到下）建议分为四个区域，区域之间用竖线分隔：

1. **应用中心入口区**：应用中心（启动台）按钮、开始按钮。
2. **固定应用区**：用户长期固定的常用应用图标，位置保持不变。
3. **运行中应用区**：当前正在运行、但没有被固定的应用，应用退出后图标自动消失。
4. **系统功能区**：回收站、小部件、系统托盘图标等。

### 4.2 图标基础交互

1. **单击图标**：应用没运行时启动应用；应用已经运行时切换到该应用窗口；应用窗口最小化时恢复窗口。
2. **重复点击运行中应用的图标**：最小化或恢复其窗口。
3. **鼠标悬停**：显示放大效果和应用名称提示；开启预览时显示窗口缩略图。
4. **拖拽排序**：用户可以直接拖动图标调整顺序，固定应用区和运行区都支持。
5. **拖出移除**：把固定应用的图标拖离 Dock 并松开，该图标从固定区移除（伴随消散动画），但不会卸载软件。

### 4.3 添加内容

1. **拖入添加**：用户可以把应用、文件、文件夹、快捷方式直接拖进 Dock。支持一次拖入多个。
2. **文件夹堆叠（Stack）**：把文件夹拖入 Dock 后，图标显示为一摞内容。单击展开，展示文件夹里的文件，可以直接打开。展开方式至少提供"网格"和"列表"两种。
3. **右键固定**：见第六部分。

### 4.4 动画效果（取各家之长）

1. 图标悬停放大、摆动、弹跳等效果，至少提供三到四种供选择。
2. 窗口最小化到 Dock 的动画。
3. Dock 自动隐藏和滑出动画。
4. 应用启动、消息到达时的图标弹跳。
5. 图标倒影随动画实时变化。
6. 可选的水波纹、流体等点击特效（作为可关闭的特色效果）。
7. 所有动画要求流畅、不掉帧，建议使用 GPU 渲染。

## 五、应用中心（类似 Launchpad 的应用总览）

### 5.1 打开方式

1. 点击 Dock 上的"应用中心"按钮打开。
2. 建议支持快捷键打开，例如按 `F` 键加一个修饰键，具体按键可在设置中修改。
3. 打开后以全屏或大窗口半透明遮罩的形式展示，背景模糊，类似 macOS 的启动台。

### 5.2 自动收集所有应用

1. 应用中心要自动扫描并显示电脑上安装的**全部应用**，不需要用户手动添加。
2. 扫描来源至少包括：
   - 开始菜单中的快捷方式（包括所有用户和当前用户两个目录）
   - 桌面上的快捷方式
   - Windows 商店安装的 UWP 应用
   - 注册表中登记的已安装程序
3. 自动去重：同一个应用有多个快捷方式时，只显示一个。
4. 自动识别图标和应用名称，显示效果整齐统一。

### 5.3 新安装应用自动加入

1. 用户新安装软件后，应用中心要自动出现该应用，不需要重启程序。
2. 实现方式可以是监听安装行为、监听快捷方式目录变化，再加上定时扫描兜底。
3. 新加入的应用建议带"新装"小标记，保留几天或用户点击后消失。
4. 应用被卸载后，应用中心对应的图标自动移除；如果快捷方式失效，也要自动清理。

### 5.4 浏览与查找

1. 应用以网格排列，图标大小统一，支持分页或滚动。
2. 顶部提供搜索框，输入应用名称可以快速定位，支持拼音搜索。
3. 支持按类别分组（如系统工具、办公、游戏、娱乐），分类可以自动识别，也允许用户自建文件夹分组。
4. 支持把应用从应用中心直接拖到 Dock 的固定区。

## 六、右键菜单

### 6.1 在 Dock 的应用图标上右键

菜单中至少包含以下选项（根据当前状态显示或隐藏）：

1. **固定在 Dock 栏中 / 从 Dock 栏取消固定**（这是必做项）。
2. 打开应用。
3. 打开应用所在的文件位置。
4. 以管理员身份运行。
5. 更换图标。
6. 修改显示名称。
7. 开机时自动启动此应用。
8. 应用正在运行时：显示窗口列表，可切换、最小化、关闭窗口；提供"退出应用"。
9. 从 Dock 栏移除（仅删除图标，不卸载软件）。
10. 查看属性。

### 6.2 在应用中心的图标上右键

1. 固定在 Dock 栏中。
2. 打开。
3. 以管理员身份运行。
4. 打开文件位置。
5. 卸载应用。
6. 从应用中心隐藏（不卸载，之后可以在设置中恢复显示）。

### 6.3 在 Dock 空白处右键

1. Dock 栏设置（打开设置卡片）。
2. 固定 / 解锁 Dock 位置。
3. 屏幕位置（底部、顶部、左侧、右侧）。
4. 自动隐藏开关。
5. 主题切换。
6. 添加小部件。
7. 隐藏 Dock 栏（相当于关闭开关）。

## 八、边界情况与异常处理

1. **UWP 应用**：应用中心和 Dock 要支持 Windows 商店应用的启动和图标显示。
2. **管理员权限**：以管理员身份运行的程序，拖放等交互可能受系统限制，请给出明确提示或替代操作方式。
3. **全屏游戏和视频**：Dock 不应强制弹出遮挡画面，按 3.2 的规则自动隐藏。
4. **资源管理器重启或崩溃**：Dock 要能自动恢复显示，不消失。
5. **分辨率变化、插拔显示器**：Dock 自动重新定位到正确位置，不跑出屏幕。
6. **快捷方式失效**：应用卸载或文件移动后，图标点击要提示"目标不存在"，并提供移除选项；应用中心自动清理。
7. **任务栏设置冲突**：系统托盘嵌入 Dock 后，要避免托盘图标重复显示或丢失。
8. **高 DPI 缩放**：在高分屏和不同缩放比例（125%、150% 等）下，图标和文字保持清晰，不模糊、不错位。

---

## 九、非功能要求

1. **性能**：Dock 常驻后台时 CPU 占用接近零，内存占用尽量低；动画保持 60 帧，不拖慢系统。
2. **渲染**：建议使用 GPU 渲染动画和模糊效果。
3. **稳定性**：Dock 崩溃不影响系统和其他软件，程序具备自动重启能力。
4. **兼容性**：明确说明支持的 Windows 版本（建议 Windows 10 和 Windows 11）。
5. **配置保存**：所有设置、固定的应用、图标排列顺序都要保存，重启后恢复。
6. **安装包**：提供安装程序，安装过程简单；最好同时提供绿色便携版本。

## 十、验收标准

完成后请逐项自测，全部满足才算合格：

1. Dock 开关位于桌面模式开关左边，样式统一。
2. 桌面模式关闭时，Dock 开关置灰不可用，并给出提示。
3. 桌面模式开启后，Dock 开关可以正常打开和关闭。
4. 打开 Dock 后，桌面模式卡片中出现"Dock 栏设置"卡片；关闭后卡片消失。
5. 关闭桌面模式时，Dock 一并关闭隐藏。
6. 设置中可以固定 Dock 位置、切换主题、开关系统托盘显示，且设置立即生效。
7. 应用中心能显示电脑上安装的全部应用，包括 UWP 应用。
8. 新安装一个软件后，应用中心自动出现该应用，无需重启。
9. 右键应用图标，菜单中出现"固定在 Dock 栏中"，固定后图标留在固定区，重启后仍在。
10. 卸载应用后，应用中心和 Dock 中的对应图标自动消失或正确提示。
11. 悬停放大、窗口预览、最小化动画、消息角标等功能正常，动画流畅。
12. 自动隐藏、多显示器、高 DPI、全屏遮挡等边界情况处理正确。
13. 重启电脑后，所有设置和固定项保持不变。
